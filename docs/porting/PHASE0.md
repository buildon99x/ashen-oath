# 원작 규칙 동결 현황

목표는 The Severed Gods Early Access v0.2.102입니다. 공식 패치의 날짜는 2026-09-11이고, 이번 조사일은 2026-10-08입니다. Godot는 사용자가 올린 4.7 프로젝트 설정을 유지합니다.

## 현재 판정

**Phase 0는 아직 통과하지 않았습니다.** 공식 소개와 패치에서 확인한 사실, 이전 빌드의 변경 기록, 실제 목표 버전에서 재현한 규칙을 구분합니다. 현재 원작 실기 기록은 없으며, 필수 EP/MP/턴/Sever/성장 계약 28개가 미확정입니다. 빈 콘텐츠 표를 100개 스킬이나 80개 유물의 구현으로 세지 않습니다.

기계 판독 가능한 근거와 미확정 값은 `rulesets/severed_v0_2_102/evidence.json`에 있습니다. `core/reference_contract.gd`는 필수 값이 미확정이거나, 홍보 설명·이전 패치 변화만 근거로 삼은 경우 목표 규칙의 활성화를 거부합니다. 이 검사 자체가 원작 동등성을 입증하지는 않습니다.

## 근거의 우선순위

1. 목표 버전을 화면에서 확인한 직접 실행 기록과 동일 입력·결과
2. 해당 버전의 조건·순서·수치를 완전히 명시한 공식 규칙
3. 공식 목표 패치의 한정된 변경 사항
4. 이전 버전 패치 및 현재 소개 문구

3–4는 조사 근거이며 누락된 공식을 채우는 기본값이 아닙니다. 자료가 충돌하면 섞어서 가상의 규칙을 만들지 않습니다. 출처 없는 팬 위키의 정밀한 수치는 채택하지 않았습니다.

- [이전 플레이테스트 공지](https://store.steampowered.com/news/posts/?enddate=1778507195&feed=steam_community_announcements): 과거 방어·반격 변경 근거이며 현재 규칙으로 자동 승격하지 않습니다.

공식 데모 링크는 Steam app4396000을 가리킵니다. 현재 웹 본문 추출에서는 홈으로 이동했으므로 현재 다운로드·실행·버전 가능 여부를 확정하지 않았습니다. 구매·로그인·게임 다운로드는 수행하지 않았습니다.

[현재 구현과 이식 목표의 전체 차이 표](GAP_MATRIX.md)에서 모듈별 재사용·교체 범위를 확인할 수 있습니다.

## 구현을 준비한 범위

기존 3인·9공격·5유물 정의를 `legacy/legacy_content.gd`로 분리했습니다. 이것은 기존 Ashen 프로토타입 자료이며 원작 데이터가 아닙니다. 현재 게임 실행은 이 기존 규칙을 사용합니다. 기존 저장, 한국어 UI, 고유 표현 자산을 유지하면서 검증된 새 데이터로 교체할 경계를 준비합니다.

사용자 기준 코드와 같은 입력으로 60개 여정, 6,882개 명령, 466번 저장·재개를 실행한 [직접 비교](../../verification/porting-phase0/legacy-parity.md)에서도 전체 상태와 RNG 기록이 일치했습니다. 이는 기존 동작 보존의 근거이며 원작 동등성·재미·새 모델로의 이전을 뜻하지 않습니다.

이전 FX 초안 PR과 미발행 작업은 별도 작업 트리에 보존했습니다. 새 메커니즘 이식에는 이전 FX 작업의 모델 불변 제한을 적용하지 않습니다. 다만 확인하지 못한 수치를 바꿔 끼우는 구현은 하지 않습니다.

## 첫 실측 기록의 필수 항목

버전 화면, 초기 영웅과 장착 목록, 동일 적·자세·부위·상태, 행동 전 자원, 입력 순서·EP 배분, 실제 실행 횟수, 행동 후 자원과 피해, 방어/Parry 실패와 성공, Knockdown 유지·회복, Sever 실행 여부·후속 행동, 보상·Empower·장착 교체를 연속으로 기록해야 합니다. 영상만 사용할 때도 버전과 앞뒤 상태가 보이지 않으면 해당 규칙을 확정하지 않습니다.

모든 기록은 출처 URL/파일, 시점 또는 프레임, 조건, 입력, 결과, 해석과 미확정 부분을 분리합니다. 원작 소스·이미지·음향·대사는 프로젝트에 복제하지 않습니다.
