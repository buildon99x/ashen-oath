점검일: 2026-10-10. 목표 명세: [원본 기획서](ashen-oath-severed-gods-mechanics-porting-plan.md).
선택 비교의 공개 기준선: `597788546b80f6deecfed0e0488f4bd37b26caff`. 이 문서가 포함된 변경은 그 기준선의 선택 결함을 보완한다.

이 표는 실제 실행 경로와 남은 기능을 구분한다. ‘임시 구현’은 사용자 승인 Ashen 정책으로 실제 전투가 작동한다는 뜻이며, 원작 EA0.2.102 동등성 통과가 아니다. 28개 목표 복합 계약은 계속 미확정으로 닫혀 있다. 원본 명세의 완료 기준이나 콘텐츠 목표를 낮추지 않는다.

## 공식 미완 기능도 완료 목표로 유지

[2026-09-11 EA v0.2.102 공식 기록에 관한 조사](BUILD_PROGRESSION_EVIDENCE.md)는 Campfire와 Morph Sigil의 개발 진행도를 50%로 명시한 부분을 구분한다. 따라서 이를 원작의 완성 기능으로 표현하지 않는다. 그렇다고 사용자 기획의 완성 목표에서 제거하지도 않는다. 다음 구현에는 확인된 기능 구조를 유지하고, 공개되지 않은 서비스·비용·변형 관계에 대한 명시적인 Ashen 임시 정의가 필요하다. 현재 기존 회복 캠프는 새 Campfire 서비스 구현의 완료가 아니다.

## 검증 해석

- [자동/실제 입력 검증](../../verification/provisional-combat/README.md)은 현재 구현 범위만 입증한다.
- 반복되는 무피해 전략이나 절단을 피하는 우세 선택은 assertion 수가 많아도 남을 수 있다. 별도의 동일 seed 전략 비교와 정상 입력 검증으로 확인한다.
- 5영웅/3월드/100+스킬/80+유물 목표는 유지한다. 빈 데이터 행, 이름만 다른 공격, UI 이름 변경을 콘텐츠 구현으로 세지 않는다.
- 성장·탐험의 공개되지 않은 수치와 표는 [추가 근거 조사](BUILD_PROGRESSION_EVIDENCE.md)에 정리했다. 임시 전투 승인을 해당 영역 전체의 숫자 선택 승인으로 확대하지 않는다.
