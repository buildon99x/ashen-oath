ASHEN OATH - The Hollow Crown
Original turn-based roguelite, release tooling for Godot 4.7.2

START
Windows x64: Extract the entire ZIP, then open ashen-oath.exe.
Linux x64: Extract the entire ZIP, then run ./ashen-oath.x86_64.
If needed on Linux, use: chmod +x ashen-oath.x86_64
No Godot editor installation, online account, or internet connection is needed.

CONTROLS
Mouse: all menus, hero/part/skill selection
1 / 2 / 3: select a hero
Up / Down: select an enemy part
Q / W / E: skill; R: Defend; T: Parry; F: manual Sever
[ / ] or wheel: reserve/cancel Boost; Space: pass actor/counter or resolve enemy
H: guide; M: mute sound; Escape: menu / return
L: Korean / English (saved separately); B: build / relics; V: character studio

New journeys use explicitly provisional Ashen combat, not verified source-game rules.
EP starts at 2, cap 6. Boost adds hits; MP is paid once. Spend no EP in a round
for +2 EP afterward. Defend halves incoming damage and restores up to 15 MP.
Read the actual limb source, height and damage in OMEN. Matching-height Parry
costs 5 MP and grants a free normal Counter on success. Break blocks its source.
Wound an exposed limb to zero, then manually Sever with 1 EP on a normal turn.
Choose another living limb or Pass/Defend to recover EP when needed. Every
limb severed or body HP zero wins. Older saved journeys keep legacy rules.
Map, rewards and permanent growth are still transitional Ashen content.
Permanent Ash upgrades are saved automatically in your user data directory.
The current journey and Ash vault save together after each accepted choice.
Resume from the title screen. A save-error warning means recent actions may
only be in memory: use Retry Save before closing. Backup recovery may require
repeating recent actions. Do not run multiple writable copies of one profile.
Korean is the default language; L switches to English. The bundled Korean
font license is in ASHEN_KOREAN_OFL.txt.

Unsigned Windows builds may trigger SmartScreen. This build is not code-signed.
The Windows export was generated and inspected on Linux; Windows-native
runtime testing is still required. See the repository's current test report.
